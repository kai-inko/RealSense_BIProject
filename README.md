# Intel's RealSense Project

Function:
- BIP_Final_Hand: Creating a 3D structure of your hand using MediaPipe
- BIP_Final_Face: Creating a 3D Mesh Structure of your face using depth recognition of RealSense Camera.

Requirement:
- Download Python, OpenCV, Open3D, Mediapipe, OneEuroFilter, Ursina, Threading, RealSense and their supporting applications.
-  

Usage:
- Code -> Download ZIP file -> Open main.py on each file -> Build

Used hardware in this project:
- Intel Core I7 10750H, 16GB RAM (a laptop)
- Intel's RealSense camera
